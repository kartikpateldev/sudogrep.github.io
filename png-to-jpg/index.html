Supported Image Formats

We support the three most common web image formats:

  • JPEG/JPG: Best suited for photographs. Our tool adjusts JPEG quality levels to find the optimal balance between file size and image clarity.
  • PNG: A lossless format that preserves background transparency. Ideal for logos, UI screenshots, and graphics with sharp edges.
  • WebP: A modern format offering superior lossy and lossless compression at smaller file sizes than JPEG or PNG.

How the Tool Works

Our compressor uses the browser's built-in HTML5 Canvas API for all processing. When you upload an image, it is decoded and drawn to a local canvas element. If you specify a target file size, the tool runs a binary-search optimization: it iteratively adjusts the export quality value until the compressed output falls within your target range. Everything happens entirely in your browser — no data is sent to any server.

Quality Considerations: Lossy vs Lossless Compression

Understanding the difference between lossy and lossless compression helps you make the right choice:

  • Lossy (JPEG, WebP lossy): Achieves the smallest file sizes by permanently discarding imperceptible visual data. Best for photographs. Aggressive compression can cause blocky artifacts and color banding.
  • Lossless (PNG, WebP lossless): Reduces file size without any quality degradation by encoding pixel data more efficiently. Ideal for logos and UI screenshots, but generally cannot reach the same small sizes as lossy formats.
  • Best practice: For portal uploads requiring small sizes, convert to JPEG or WebP. For design assets where pixel accuracy matters, use PNG.

Privacy and Browser-Based Processing

All processing, resizing, and file optimization happen locally in your web browser using client-side JavaScript. No images are uploaded to any external server at any point. Your photos, personal IDs, and signatures never leave your device.

Common Problems and Solutions

  • File is still too large after compression: If a PNG file will not shrink enough, switch the output format to JPEG or WebP. Alternatively, resize the image dimensions first to reduce the total pixel count, then re-compress.
  • Image looks blurry or blocky: A high-resolution image compressed to a very small size loses significant data. Resize dimensions first — smaller pixel dimensions require far less quality reduction to hit the same kilobyte target.
  • Compressed file is larger than the original: This happens when you convert JPEG to PNG (lossless). Select JPEG or WebP to ensure a smaller output than the original JPEG.
  • Portal rejects the uploaded file: Most portals require JPEG format. Select JPEG as the output format before downloading.
